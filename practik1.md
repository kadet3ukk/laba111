А вот совсем уже безобидный код. Циклов нет, но программа зависает. Почему?

```python

2 ** z
```

Причина зависания в том, что после сдвига число `z` становится очень большим. Операция возведения в степень `2 ** z` требует огромного количества вычислений и памяти.

## 1.6

Да-да, и этот код зацикливается! А тут-то что не так?

```python
i = 0

while i < 10:
    print(i)
    ++i
```

В Python операция `++i` не увеличивает значение переменной. Она воспринимается как два знака `+`, поэтому переменная `i` не изменяется и цикл становится бесконечным.

Исправленный вариант:

```python
i = 0

while i < 10:
    print(i)
    i += 1
```

## 1.8

В Python можно использовать цепочки операций сравнения.

Первый пример:

```python
x = 5

1 < x < 10
```

Это сокращённая запись:

```python
1 < x and x < 10
```

Сначала проверяется, что `x` больше 1, затем что `x` меньше 10.


Второй пример:

```python
x = 5

1 < (x < 10)
```

Сначала выполняется сравнение:

```python
x < 10
```

Получается значение `True`.

В Python `True` имеет значение 1, поэтому выражение становится:

```python
1 < 1
```

# 2. Сообщения об ошибках

## 2.1 SyntaxError: invalid syntax

Ошибка возникает из-за неправильного синтаксиса.

```python
print("Hello"
```

---

## 2.2 SyntaxError: cannot assign to literal

Ошибка возникает при попытке присвоить значение числу.

```python
10 = x
```

---

## 2.3 NameError: name is not defined

Ошибка возникает при обращении к переменной, которая не была создана.

```python
print(a)
```

---

## 2.4 SyntaxError: unterminated string literal

Ошибка возникает из-за незакрытой строки.

```python
print("Hello)
```

---

## 2.5 TypeError: unsupported operand type(s)

Ошибка возникает при попытке выполнить операцию с несовместимыми типами данных.

```python
a = 5
b = "text"

print(a + b)
```

---

## 2.6 IndentationError: expected an indented block

Ошибка возникает, если после условия отсутствует отступ.

```python
if True:
print("Hello")
```

---

## 2.7 IndentationError: unindent does not match any outer indentation level

Ошибка возникает из-за неправильных отступов.

```python
if True:
    print("Hello")
  print("World")
```

---

## 2.8 ValueError: math domain error

Ошибка возникает при передаче неправильного значения в математическую функцию.

```python
import math

print(math.sqrt(-1))
```


## 2.9

OverflowError: math range error

Ошибка возникает при попытке выполнить математическую операцию с числом, которое выходит за допустимый диапазон.

```python
import math

print(math.exp(1000))
```
